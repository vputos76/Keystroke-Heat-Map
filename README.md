Shows real-time feedback on the keys you are typing (either your own ideas or a suggested prompt).

Typing the same key repeatedly increases the "heat", changing the tile colour from blue -> green -> yellow -> red.
Avoiding the key for a short time allows it to "cool", changing back from red -> yellow -> green -> blue.
